# FreeFileServer

## What is FreeFileServer?
FreeFileServer is an extremely simplistic HTTP file server written in Python. It enables to share a directory on your browser over any network. It was written from scratch with zero AI.

No external dependencies.


## Usage
clone this repo:

```
git clone https://github.com/atifcodesalot/freefileserver
```

Finally:

```
python3 -m freefileserver [file-path]
```
