# FreeFileServer

## What is FreeFileServer?
FreeFileServer is an extremely simplistic HTTP file server written in Python. It enables to share a directory on your browser over any network.


## Usage
clone this repo:

```
git clone https://github.com/atifcodesalot/freefileserver
```
Then install the required packages via pip:

```
python3 -m pip install -r requirements.txt
```

Finally:

```
python3 -m freefileserver [file-path]
```
